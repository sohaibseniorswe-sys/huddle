# Agent rules

- Work on one branch per issue (agent/issue-<n>), open a pull request that closes the issue, and merge it yourself once the tests and CI pass.
- Run the project's tests before every push. Add tests for new behaviour.
- Keep main green: merge only when the build passes.
- Write down any assumption in the issue or the pull request.
- Huddle and the control issue: follow the operating principles in your launch prompt.
