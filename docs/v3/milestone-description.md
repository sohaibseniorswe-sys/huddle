Huddle v3 turns the working v1 loop into an application you set up and drive from one terminal screen: a Bubble Tea UI with a fixed, predictable layout; a companion agent you talk to while Codex and the PM work, with decisions that reach the control issue only when you agree; free choice of Codex or Claude Code (with model and effort) for every role; a setup wizard; a single autonomy dial; and start modes for planning new milestones or running existing ones.
